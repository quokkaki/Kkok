# 꼭 (Kkok)
> 까먹으면 안 되는 일, 딱 몇 개만.

계획은 다이어리에, **꼭 해야 하는 것**만 잠금화면에.
꼭은 할 일을 많이 쌓아 두는 앱이 아니라, 폰을 켤 때마다 눈에 들어오도록 몇 개만 꽂아 두는 투두 앱입니다.

## 이렇게 써요
- **＋** 버튼으로 할 일을 적어요. 제목 한 줄이면 충분해요
- 끝낸 일은 탭해서 체크해요. 잠깐 회색으로 남았다가 조용히 사라져요
- 필요 없어진 일은 옆으로 밀어서 지워요
- 잠금화면 위젯에서 남은 할 일을 바로 확인해요
